# Expense Tracker CLI

A command-line interface (CLI) Python application to track your personal expenses. Data is persistently stored using JSON file handling.

## Features
1. Add an expense (Amount and Description)
2. View all expenses
3. Delete an expense
4. Calculate total spending

## How to Run
1. Ensure Python 3.x is installed on your machine.
2. Clone this repository.
3. Open your terminal and navigate to the `src` directory:
